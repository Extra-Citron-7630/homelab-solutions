# Homelab Solutions

Modern React/Vite marketing site for Homelab Solutions.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Before publishing

1. Review the content in `src/main.jsx`.
2. Push the repository to GitHub and deploy it with GitHub Pages or another static host.
3. Consider adding a custom domain when you're ready.

## Suggested repository name

`homelab-solutions`
